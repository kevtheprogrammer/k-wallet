# k-wallet
 This is a banking core system that runs on Python.
 It's a CLI banking app,
 it has most banking functions
 Feel free to contribute
 on respective branches i.e v1, v2, v3..
 
# Environment
 use UV to set up env
 run "uv init --no-package"


# Databsae
 set up database
 run "pip install sqlalchemy"

# Features

 1. User Creation
 2. User Authentication
 3. Send Money
 4. Deposit Money
 5. Balance Inquiry
 6. Withdraw
